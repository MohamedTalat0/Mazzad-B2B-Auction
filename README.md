# Mazad – Multi-Tenant B2B Auction Platform

A team-based backend project built with **ASP.NET Core** that enables businesses to create, manage, and participate in online auctions through a secure multi-tenant architecture.

## Tech Stack

- ASP.NET Core Web API
- C#
- Entity Framework Core
- SQL Server
- ASP.NET Core Identity
- JWT Authentication
- Clean Architecture
- SignalR
- LINQ
- Git & GitHub

## Key Features

- Multi-tenant architecture
- Secure Authentication & Authorization
- Role-Based Access Control (RBAC)
- JWT Authentication
- Real-time notifications using SignalR
- Auction creation and management
- Bidding system
- RESTful APIs
- Entity Framework Core & SQL Server
